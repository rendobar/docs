Two clips side by side on a track cut straight from one to the other. To blend them, put a transition clip between them in the track's list. Ordinary clips have no transition field.

```json
"clips": [
  { "asset": { "type": "video", "src": "https://example.com/a.mp4" } },
  { "type": "transition", "transition": "crossfade", "duration": 0.8 },
  { "asset": { "type": "video", "src": "https://example.com/b.mp4" } }
]
```

A scene instead takes a `transition` field that sets how it enters from the scene before.

The blend overlaps the two clips, so a transition never makes the render longer.

## The seven kinds

`crossfade` dissolves one picture into the other. `fade` dips to black, like a chapter break. `slide` moves the new clip in over the old one. `push` moves the old one out of frame. `wipe` reveals the new clip in place, along a moving edge or through a shape. `zoom` scales into the new clip. `none` is a hard cut, which professional editors use for almost every join.

## Direction

`slide`, `push` and an `edge` wipe take a `direction` for the way the picture moves: `left`, `right`, `up` or `down`.

```json
{ "type": "transition", "transition": "push", "direction": "up", "duration": 0.5 }
```

## Wipe shapes

A wipe's `shape` defaults to `edge`, a straight line moving in `direction`. `circle` opens from the centre, `box` opens as a rectangle, and `barnDoorHorizontal` and `barnDoorVertical` split from the middle outwards.

```json
{ "type": "transition", "transition": "wipe", "shape": "circle", "duration": 0.8 }
```

## Your own wipe

`map` takes the URL of a greyscale image and wipes in its pattern. Black areas change first, white last, and greys in between. A radial gradient gives a circular iris and a brush stroke gives a painted reveal. A `map` replaces both `shape` and `direction`.

```json
{ "type": "transition", "transition": "wipe", "map": "https://example.com/brush-wipe.png", "duration": 1 }
```

## How long it can be

A transition cannot be longer than either clip it joins. Ask for more and the render shortens it to fit and adds a warning to the job, so a template made for long clips still works with a short one. [Validation](/docs/jobs/compose/pricing#check-a-timeline-before-you-render) reports the same warning before you spend anything.

## How to use them

Cut hard for most joins and keep crossfades under 10% of them. Use one decorative style (slide or zoom) per video, and only between sections.

| Use | Transition | Duration |
| --- | --- | --- |
| Almost every join | none (hard cut) | 0 |
| Time passes, mood softens | `crossfade` | 0.6 to 1.0s |
| Chapter break | `fade` | 1 to 2s |
| Energy, social | `slide`, `push` or `zoom` | 0.3 to 0.7s |

Every field is in the [transition reference](/docs/jobs/compose/reference/transition).
