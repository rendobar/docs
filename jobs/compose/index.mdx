`compose` renders a video from a JSON timeline. You start with one clip and add more clips, transitions, overlays and effects as you need them.

## Your simplest render

The smallest timeline is one track with one clip. This call renders the first three seconds of a video to MP4.

<CodeGroup>

```ts SDK
import { createClient, outputUrl } from "@rendobar/sdk";

const client = createClient({ apiKey: "rb_YOUR_KEY" });

// run() creates the job and waits for it to finish.
const job = await client.jobs.run({
  type: "compose",
  params: {
    schemaVersion: 1,
    output: {
      format: "mp4",
      resolution: { width: 1080, height: 1920 },
      fps: 30,
    },
    timeline: {
      tracks: [
        {
          clips: [
            {
              asset: {
                type: "video",
                src: "https://cdn.rendobar.com/assets/examples/sea.mp4",
              },
              start: 0,
              length: 3,
            },
          ],
        },
      ],
    },
  },
});

console.log(outputUrl(job));
```

Without `trim`, a clip plays its source from the start for `length` seconds. Leave `length` off and it plays the whole source. To play one segment, add `trim: { from, to }` to the asset, in source seconds. `length` sets how long the clip lasts on the timeline, and `trim` picks which part of the source fills that time.

## Join two clips

Put a second clip on the same track and a transition between them.

```json
"clips": [
  { "asset": { "type": "video", "src": "https://cdn.rendobar.com/assets/examples/river.mp4" } },
  { "type": "transition", "transition": "crossfade", "duration": 1 },
  { "asset": { "type": "video", "src": "https://cdn.rendobar.com/assets/examples/forest.mp4" } }
]
```

You set no timing here. Each clip plays its whole source, the second starts after the first, and the transition overlaps them by its `duration`. You do not need to know how long either file is.

You can also write the timing out. This gives the same render, with the second clip starting `duration` seconds before the first ends.

```json
"clips": [
  { "asset": { "type": "video", "src": "https://cdn.rendobar.com/assets/examples/river.mp4" }, "start": 0, "length": 3 },
  { "type": "transition", "transition": "crossfade", "duration": 1 },
  { "asset": { "type": "video", "src": "https://cdn.rendobar.com/assets/examples/forest.mp4" }, "start": 2, "length": 3 }
]
```
