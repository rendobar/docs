Set `asset.type` to `"subtitles"`. These are its own fields, on top of the [clip fields](/docs/jobs/compose/reference/timeline#clip) every clip takes.

| Field | Type | What it does |
| --- | --- | --- |
| `cues` | object[] | The lines, in order. Times count from the start of the clip, so moving the clip moves its subtitles. Or give `src` instead. |
| `cues.start` * | number | When the line appears, in seconds from the start of THIS clip. min 0. |
| `cues.end` * | number | When the line goes, in seconds from the start of this clip. over 0. |
| `cues.text` * | string | The line. Keep it to two short rows. |
| `src` | string | An .srt or .vtt file with the lines, instead of `cues`: what a transcription service, or the caption.extract job, gives you. Its times count from the start of the clip. |
| `reveal` | `"line"` \| `"typewriter"` | line shows each cue at once, typewriter types it out word by word, the social-video style. default `"line"`. |
| `style` * | object |  |
| `style.font` | string | Font family, or a CSS fallback stack. Any Google Fonts family works by name. Bundled and instant: Inter, Bebas Neue, Anton, Montserrat, Poppins, Roboto, Oswald. Families declared in the `fonts` job input win over both. A stack falls through in CSS order, so "Display, Inter, sans-serif" tries each in turn. default `"Inter"`. |
| `style.size` * | number | Font size in pixels of the output frame. ~64-96 for titles at 1080p, ~36-48 for lower thirds. over 0. |
| `style.weight` | integer | Font weight 100..1000 (400 regular, 700 bold, 800+ display). Honoured exactly on variable fonts; snapped to the nearest available weight otherwise. default `400`, min 100, max 1000. |
| `style.italic` | boolean | Render the italic cut of the family, when it has one. default `false`. |
| `style.color` | string | Text fill color, hex like "#FFFFFF". default `"#FFFFFF"`, pattern `^#([0-9A-Fa-f]{3}|[0-9A-Fa-f]{6}|[0-9A-Fa-f]{8})$`. |
| `style.stroke` | object | Outline around the glyphs. A 2-4px black stroke keeps white text readable on bright footage. |
| `style.background` | string | Solid box color behind the text, hex. Omit for no box. pattern `^#([0-9A-Fa-f]{3}|[0-9A-Fa-f]{6}|[0-9A-Fa-f]{8})$`. |
| `style.align` | `"left"` \| `"center"` \| `"right"` | How the lines line up, and which side of the text sits on the clip's transform.position x: left starts there, center is centred on it, right ends there. Place the text with the clip's transform, not here. default `"center"`. |
| `style.animate` | object | Entrance animation. Omit for text that is simply present. |
| `style.shadow` | object | Drop shadow behind the text, adds depth and readability. |

Fields marked `*` are required. Every table on this page is generated from the schema the API validates with, so it cannot drift from what a render accepts.
