Set `asset.type` to `"video"`. These are its own fields, on top of the [clip fields](/docs/jobs/compose/reference/timeline#clip) every clip takes.

| Field | Type | What it does |
| --- | --- | --- |
| `src` * | string | Video URL: an https URL or an uploaded asset's content URL. |
| `trim` | object | Which part of the source file to use, in source seconds. Omit to play from the start. |
| `trim.from` * | number | Start second in the SOURCE file. min 0. |
| `trim.to` * | number | End second in the SOURCE file (exclusive). over 0. |
| `volume` | number \| object[] | Audio gain for this clip: 1 = source level, 0 mutes, 0.2 ducks it under a music track. Keyframes change it over time. default `1`. |

Fields marked `*` are required. Every table on this page is generated from the schema the API validates with, so it cannot drift from what a render accepts.
