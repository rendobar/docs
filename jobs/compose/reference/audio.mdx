Set `asset.type` to `"audio"`. These are its own fields, on top of the [clip fields](/docs/jobs/compose/reference/timeline#clip) every clip takes.

| Field | Type | What it does |
| --- | --- | --- |
| `src` * | string | Audio URL (mp3/wav/aac). Put music on its own track under the video tracks. |
| `trim` | object | Which part of the source file to use, in source seconds. Omit to play from the start. |
| `trim.from` * | number | Start second in the SOURCE file. min 0. |
| `trim.to` * | number | End second in the SOURCE file (exclusive). over 0. |
| `volume` | number \| object[] | Gain: 1 = source level. 0.2-0.4 sits music under speech. Keyframes duck it: drop to 0.2 while someone speaks and back to 1 after. default `1`. |
| `fadeIn` | number | Seconds to ramp in from silence. Works with `volume` keyframes: the fade shapes whatever level they set. default `0`, min 0. |
| `fadeOut` | number | Seconds to ramp out to silence at the clip's end. Works with `volume` keyframes, like `fadeIn`. default `0`, min 0. |

Fields marked `*` are required. Every table on this page is generated from the schema the API validates with, so it cannot drift from what a render accepts.
