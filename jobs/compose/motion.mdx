To animate a numeric field, give it a list of keyframes instead of a value. [Where keyframes are accepted](#where-keyframes-are-accepted) lists every field that takes one.

```json
"transform": {
  "scale": [
    { "time": "0%", "value": 1, "easing": "easeInOutSine" },
    { "time": "100%", "value": 1.12 }
  ]
}
```

- `time` is seconds from the clip's start or a percent of its length. `"100%"` is the last frame, whatever the clip's length.
- `easing` sets the curve from that keyframe to the next, so put it on the first of a pair. The last keyframe's easing is never used. There are 33 easings, listed below.

The example above is a Ken Burns push-in. Use the same keyframes on `opacity` for a fade, on a shape's `color` for a colour change, or on `volume` to duck music under a voice.

## Where keyframes are accepted

`transform.position`, `transform.scale`, `transform.rotate`, `transform.rotateX`, `transform.rotateY`, `transform.size` (a box's size), `transform.corners` (the four corners of a pin), clip `opacity`, `asset.volume` on video and audio, a shape's `color` and `radius`, and every effect parameter marked animatable in the [effect reference](/docs/jobs/compose/reference/effects).

## Turning in 3D

`rotateY` turns a clip around its vertical axis and `rotateX` tips it around its horizontal axis. Both are in degrees and take keyframes. `perspective` is the viewer's distance from the frame in pixels. 600 looks dramatic, 2000 looks subtle, and the default is 1200. The clip turns about its `anchor`.

```json
"transform": {
  "scale": 0.62,
  "rotateY": [
    { "time": 0, "value": -80, "easing": "easeOutCubic" },
    { "time": 1.4, "value": -18 }
  ],
  "perspective": 900
}
```

## The 33 easings

`step` holds the value until the next keyframe. `linear` moves at a constant rate. `smooth` curves through every keyframe, so a move across several keyframes has no sharp corners. The other 30 are the `easeIn`, `easeOut` and `easeInOut` families over Sine, Quad, Cubic, Quart, Quint, Expo, Circ, Back, Elastic and Bounce.

Back, Elastic and Bounce overshoot the value you set, by design. When you use one on `position`, leave room at the edges of the frame.
