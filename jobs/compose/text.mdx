A text clip carries its own words, its own style and its own box. Three neighbouring clip kinds cover the jobs text is usually asked to do: a clock that counts, a subtitles clip that holds every line, and a Lottie animation exported by a designer.


A `text` asset renders a styled title. `style` holds the type: `font`, `size`, `weight`, `color`, `align`, a `stroke`, a `background` box, a `shadow`, and an `animate` entrance (`fade`, `slideUp`, `slideDown`, `slideLeft`, `slideRight`). `font` takes any Google Fonts family by name, or a family from your own file. See [Fonts](#fonts).

Where it sits is the clip's `transform`, the same field that places every other clip.

```json
{
  "asset": {
    "type": "text",
    "text": "Coastal Escape",
    "style": {
      "font": "Inter",
      "size": 84,
      "weight": 800,
      "color": "#FFFFFF",
      "stroke": { "color": "#000000", "width": 6 },
      "animate": { "type": "slideUp", "duration": 0.7 }
    }
  },
  "transform": { "position": { "x": "50%", "y": "38%" } },
  "start": 0,
  "length": 3
}
```

Colours are hex: `#RGB`, `#RRGGBB`, or `#RRGGBBAA` with alpha.

## A clock


A `timer` counts over the clip's own length, up or down, in the format you name.

```json
{ "asset": { "type": "timer", "direction": "down", "format": "MM:SS", "style": { "font": "JetBrains Mono", "size": 96, "color": "#FFFFFF" } }, "start": 0, "length": 10 }
```

`format` is `SS`, `SS.S`, `SS.SS`, `MM:SS`, `MM:SS.SS` or `HH:MM:SS`. It takes the same `style` as text.

## Subtitles


One `subtitles` clip holds every line, either written in the timeline or read from an `.srt` or `.vtt` file. Times are seconds from the clip's start.

```json
{ "asset": { "type": "subtitles", "cues": [
    { "start": 0, "end": 1.8, "text": "Subtitles live in the timeline." },
    { "start": 2, "end": 4, "text": "One clip, every line." }
  ], "reveal": "typewriter", "style": { "font": "Inter", "size": 44, "color": "#FFFFFF", "background": "#000000B0" } },
  "transform": { "position": { "x": "50%", "y": "88%" }, "anchor": "topLeft" } }
```

Or point it at a file: `{ "type": "subtitles", "src": "https://example.com/captions.srt" }`. For word-level captions burned from speech instead, see [animated captions](/jobs/captions/animate).

## Lottie animations


An `animation` asset plays a Lottie `.json` file, the kind After Effects, Figma and LottieFiles export, with a transparent background. It plays once, for its own length, and fits the frame like an image.

```json
{ "asset": { "type": "animation", "src": "https://example.com/logo-reveal.json" }, "transform": { "scale": 0.4, "position": { "x": "50%", "y": "50%" } } }
```

Export it self-contained: a file that pulls images or fonts from elsewhere is refused, because nothing reaches the renderer except through the checked download.

Fonts are their own page: [Fonts and languages](/docs/jobs/compose/fonts). Every text field is in the [text reference](/docs/jobs/compose/reference/text).
