A `text` clip renders a styled title. `style` holds `font`, `size`, `weight`, `italic`, `color`, `align`, a `stroke`, a `background` box, a `shadow` and `animate`, which sets the entrance (`fade`, `slideUp`, `slideDown`, `slideLeft`, `slideRight`, `blur` or `scale`), whether it arrives a letter, word or line at a time, and the exit. `font` takes any Google Fonts family by name, a bundled family, or your own file. See [Fonts and languages](/docs/jobs/compose/fonts).

Captions and timers are separate clips, on [Subtitles and timers](/docs/jobs/compose/captions). Lottie animations are on [Media clips](/docs/jobs/compose/media#lottie-animations).

Place the text with `transform`, like any other clip.

```json
{
  "asset": {
    "type": "text",
    "text": "Coastal Escape",
    "style": {
      "font": "Inter",
      "size": 84,
      "weight": 800,
      "color": "#FFFFFF",
      "stroke": { "color": "#000000", "width": 6 },
      "animate": { "type": "slideUp", "duration": 0.7 }
    }
  },
  "transform": { "position": { "x": "50%", "y": "38%" } },
  "start": 0,
  "length": 3
}
```

Colours are hex: `#RGB`, `#RRGGBB`, or `#RRGGBBAA` with alpha. `weight` runs from 100 to 1000, and `italic: true` slants the text. Text does not wrap to a width, so put a line break (`
`) in `text` where each new line starts. Keep a title to two to six words.

## Kinetic titles

`by` splits the text so it arrives one unit at a time: `"letter"`, `"word"` or `"line"`. `duration` is when the last unit lands. `stagger` is the gap between the start of one unit and the next. `order` picks which unit goes first: `start`, `end`, `center`, `edges` or `random`. `random` uses a seed from the clip, so re-renders match.

```json
{
  "asset": {
    "type": "text",
    "text": "AFTER DARK",
    "style": {
      "font": "Inter",
      "size": 58,
      "weight": 800,
      "animate": { "type": "slideUp", "by": "word", "duration": 1.1 }
    }
  },
  "transform": { "position": { "x": "50%", "y": "46%" } },
  "start": 0,
  "length": 6
}
```

Split one title per scene at most. On body text or captions, a split slows reading.

## Leaving

`out` animates the text away over the clip's last `duration` seconds, with any motion `type` takes and the same split and order. Without `out`, the text stays until the clip ends.

```json
"animate": { "type": "fade", "duration": 0.6, "out": "blur" }
```

<Note>
A split, an exit, or a `blur` or `scale` entrance makes the clip an animated graphic. It costs the same per minute, and renders up to 1080p at 30 fps on every self-serve plan. A `fade` or a slide of the whole title does not count as one. See [what each plan renders](/docs/jobs/compose/pricing#what-each-plan-renders).
</Note>
