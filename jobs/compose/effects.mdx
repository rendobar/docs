Effects are a list that runs in the order you write it. Put it on a clip, a track or the whole timeline.

```json
{
  "asset": { "type": "video", "src": "https://cdn.rendobar.com/assets/examples/sea.mp4" },
  "start": 0,
  "length": 3,
  "effects": [
    { "type": "color", "saturation": 1.2, "temperature": 6800 },
    { "type": "vignette" }
  ]
}
```

On a track, it applies to every clip. On the timeline, it applies to the finished video, so put a grade for the whole edit there.

```json
"timeline": {
  "effects": [{ "type": "look", "name": "muted" }],
  "tracks": [
    { "effects": [{ "type": "grain" }], "clips": [{ "asset": { "type": "video", "src": "https://cdn.rendobar.com/assets/examples/sea.mp4" } }] }
  ]
}
```

Set an optional `start` and `length`, in seconds or as a percent of what the effect sits on, to run it for part of a clip. Keyframe any numeric parameter to change it over time.

```json
{ "type": "blur", "radius": [{ "time": "0%", "value": 14, "easing": "easeOutCubic" }, { "time": 1, "value": 0 }] }
```

There are 34 built-in effects, 23 for the picture and 11 for sound, with parameters in real units. The [Compose features page](https://rendobar.com/compose/features/#picture) shows each one before and after. Picture effects:

| Effect | What it does |
| --- | --- |
| `color` | Grade by hand: brightness, contrast, saturation, gamma, hue and temperature. Every setting is optional. |
| `look` | A one-word look: greyscale, boost, muted, lighten, darken, contrast, negative, sepia or oldFilm. |
| `lut` | Grade with a `.cube` LUT, the file a colourist or a grading app exports. |
| `blur` | Soften the picture. 5 to 15 makes a backdrop that keeps text over it readable. |
| `sharpen` | Sharpen soft footage. |
| `denoise` | Remove the grain a small camera sensor adds in low light. |
| `glow` | Make the bright parts bloom. Best on lights against a dark frame. |
| `grain` | Add film grain, so digital footage looks less clinical. |
| `vignette` | Darken the corners to pull the eye to the middle. |
| `shake` | Make a steady shot look handheld. The picture zooms in a little so its edges never show. |
| `glitch` | Blocks of the picture jump sideways and the colours tear. Give it a short length. |
| `pixelate` | Large square pixels over the whole picture. |
| `posterize` | Flatten the picture into a few steps of each colour, like a screen print. |
| `rgbShift` | Pull the red and blue channels apart for an analogue look. |
| `scanLines` | The dark lines of a CRT monitor. |
| `sketch` | Turn the picture into a pencil drawing. |
| `trails` | Moving lights and people leave streaks. Needs a camera that does not move. |
| `chromaKey` | Remove a green screen or any solid colour, so the track below shows through. |
| `mask` | Show the clip only where an image says: white or opaque keeps it, black or clear cuts it. |
| `blurRegion` | Blur one part of the picture: a face, a number plate, a screen. |
| `outline` | Draw a line around a layer with transparency, such as a keyed subject or a logo. |
| `dropShadow` | Add a soft shadow under a layer with transparency, so it stands out from the background. |
| `visualizer` | Draw the sound over the picture as a waveform or a spectrum. |

The 11 sound effects are on [Audio and mixing](/docs/jobs/compose/audio#sound-effects).

Two effects read a file. `lut` takes a `.cube` grade and `mask` takes an image that sets which parts of the clip show. The file is fetched and checked like any clip source.

```json
{ "type": "mask", "src": "https://cdn.rendobar.com/assets/brand/logo-mark.png", "channel": "alpha" }
```

A picture effect on a clip with no picture, or a sound effect on a silent clip, returns a 400. Text and shapes draw their own outline and shadow, so you cannot put `outline` or `dropShadow` on them.

## Colour

`color` holds brightness, contrast, saturation, temperature and the rest in one effect. `look` applies a ready-made look in one word. `lut` takes a `.cube` file you supply.

## Anything the engine can do

If no built-in effect fits, `{ "type": "engine" }` reaches more than 300 other filters by name. A typo in a filter or parameter returns a 400 before the job starts.

```json
{ "type": "engine", "filter": "colorize", "params": { "hue": 200, "saturation": 0.6 } }
```

FFmpeg filters use their FFmpeg name and option names, so `colorize` takes `hue`, `saturation` and `lightness`. Other filters use a camelCase name, such as `cartoon` with `triplevel` and `diffspace`. `GET /compose/effects/engine` lists every filter an engine entry can name, with its parameters. `GET /compose/effects` does the same for the built-in effects.

An engine entry that repeats a built-in effect is refused. The engine's filter list can change when the engine is upgraded. The built-in effects do not.

The [effect reference](/docs/jobs/compose/reference/effects) lists every effect and parameter. Sound effects are on [Audio and mixing](/docs/jobs/compose/audio).
