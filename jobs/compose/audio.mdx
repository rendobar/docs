Sound comes from `audio` clips and from the sound in `video` clips. All tracks with sound play at once in one mix. Set each clip's level, then shape the sound with effects on a clip, a track or the whole mix.

```json
{
  "asset": { "type": "audio", "src": "https://example.com/music.mp3", "volume": 0.35, "fadeIn": 1.5, "fadeOut": 3 },
  "length": "end"
}
```

`length: "end"` runs the music to the end of the video, however long it is.

## Levels

`volume` is linear gain on a `video` or `audio` asset. `1` keeps the source level and `0` mutes it. Under speech at `1`, set music to `0.2` to `0.4`. On its own, set it to `0.35` to `0.5`.

`fadeIn` and `fadeOut` fade an audio clip in from silence and out to silence, in seconds. Fade music in over 1 to 2 seconds and out over 3 to 5, ending on the last frame.

## Ducking music under a voice

Use one music clip and keyframe its `volume`: up before the first word, down under the speech, up again after. `fadeIn` and `fadeOut` still apply on top.

```json
{
  "asset": {
    "type": "audio",
    "src": "https://example.com/music.mp3",
    "volume": [
      { "time": 0, "value": 0.4 },
      { "time": 2.5, "value": 0.2, "easing": "easeInOutSine" },
      { "time": 9, "value": 0.2 },
      { "time": 9.6, "value": 0.4 }
    ],
    "fadeOut": 3
  },
  "length": "end"
}
```

## Panning

`pan` places a clip's sound from `-1` (full left) through `0` (centred) to `1` (full right). It works on any clip with sound.

```json
{ "asset": { "type": "audio", "src": "https://example.com/door-knock.mp3" }, "start": 4, "pan": -0.6 }
```

## The mix

Music, a voice-over and the footage's own sound need no separate mixing step. An `effects` list works on a clip, a track or the timeline:

- On a clip, it changes that clip's sound.
- On a track (`track.effects`), it changes everything on the track, such as every line of a voice-over at once.
- On the timeline (`timeline.effects`), it changes the final mix. Put a `limiter` or a `loudness` target here.

```json
"timeline": {
  "tracks": [
    { "clips": [{ "asset": { "type": "video", "src": "https://example.com/interview.mp4" } }] },
    { "clips": [{ "asset": { "type": "audio", "src": "https://example.com/music.mp3", "volume": 0.25 }, "length": "end" }] }
  ],
  "effects": [{ "type": "loudness" }, { "type": "limiter" }]
}
```

## Sound effects

Each effect is an entry with a `type` and only the settings you change.

| Effect | What it does |
| --- | --- |
| `loudness` | Sets sound to a standard loudness. Use -16 LUFS for online video and podcasts, -23 for broadcast. |
| `voiceDenoise` | Removes steady background noise from under speech: a river, a fan, a street. Not for music. |
| `gate` | Mutes the sound between phrases, so room noise drops out in the pauses. |
| `highPass` | Cuts everything below a frequency. Wind, traffic and handling noise sit below the voice. |
| `lowPass` | Cuts everything above a frequency: music from the next room, or a voice on the phone. |
| `eq` | Three-band tone control: more bass and treble on music, or less boom on a voice. |
| `compressor` | Evens out a voice so quiet and loud words play at the same level. |
| `limiter` | Stops peaks from clipping, with optional gain to make a track louder. |
| `pitch` | Raises or lowers the pitch without changing the speed. |
| `echo` | Adds a repeat behind the sound. |
| `reverb` | Makes a dry voice sound like it is in a hall. |

A typical voice chain is `highPass`, then `voiceDenoise`, then `compressor`, then `loudness`.

```json
"effects": [{ "type": "highPass", "cutoff": 80 }, { "type": "voiceDenoise" }, { "type": "compressor" }, { "type": "loudness" }]
```

## Sound drawn on the picture

`visualizer` draws the sound over the picture as a `waveform` or a `spectrum`, for an audiogram or a podcast clip. On the timeline, its usual place, it draws the final mix. On a track or a clip, it draws only that sound.

```json
"effects": [{ "type": "visualizer", "kind": "waveform", "color": "#34D399", "y": "80%", "width": "76%", "height": "20%" }]
```
