`output` sets the file you get back. Without it, you get a 1080p mp4 at 30 fps.

```json
"output": { "format": "mp4", "size": "reels", "fps": 30, "quality": "high" }
```

A compose job renders one file. For two sizes of the same edit, submit two jobs. They render at the same time.

## Formats

| `format` | You get |
| --- | --- |
| `mp4` | Video with sound, H.264 and AAC. The default. |
| `webm` | Video with sound, VP9 and Opus. Keeps a transparent background. |
| `gif` | An animated image, with no sound. |
| `mp3` | Sound alone. Needs no frame size. |
| `jpg` | One frame, as a still. |
| `png` | One frame, as a still. Keeps a transparent background. |

## Size

Set a `size` preset or an exact `resolution`. If you set both, `resolution` wins. Every format except `mp3` needs one of them.

```json
"output": { "format": "mp4", "resolution": { "width": 1080, "height": 1350 } }
```

| `size` | Pixels |
| --- | --- |
| `360p` | 640 x 360 |
| `720p` | 1280 x 720 |
| `1080p` | 1920 x 1080 |
| `1440p` | 2560 x 1440 |
| `4k` | 3840 x 2160 |
| `tiktok`, `reels`, `shorts`, `instagram-story` | 1080 x 1920 |
| `instagram-feed` | 1080 x 1350 |
| `square` | 1080 x 1080 |
| `youtube-hd`, `x-landscape`, `linkedin` | 1920 x 1080 |
| `youtube-4k` | 3840 x 2160 |

For a vertical Reel from landscape footage, set `"fit": "cover"` to fill the frame, or `"fit": "blur"` to show the whole picture over a blurred copy of itself. See [how a picture fills its box](/docs/jobs/compose/framing#how-a-picture-fills-its-box).

## Frame rate

`fps` sets the frame rate, 30 by default. Each plan caps frame size and frame rate together: 1080p at 30 fps on Free, 1440p at 30 fps on Pro, and 4K at 60 fps on Studio. Animated graphics render up to 1080p at 30 fps on every self-serve plan. A video above your plan returns `403 PLAN_LIMIT` at submit, and [validation](/docs/jobs/compose/pricing#check-a-timeline-before-you-render) catches it first. See [what each plan renders](/docs/jobs/compose/pricing#what-each-plan-renders).

## Quality

`quality` trades picture quality against file size and render time.

| `quality` | For |
| --- | --- |
| `draft` | A fast preview |
| `standard` | Web delivery. The default. |
| `high` | A sharper master, slower to encode |
| `max` | The highest fidelity, slowest to encode |

To set the encoder yourself, these override `quality`:

| Field | Takes |
| --- | --- |
| `videoCodec` | `h264` (the mp4 default) or `vp9`. webm is always vp9. |
| `audioCodec` | `aac` (the mp4 default), `opus` or `mp3`. webm is always opus. |
| `crf` | Constant rate factor. Lower means better quality and a larger file: 0 to 51 for h264, 0 to 63 for vp9. Not for gif, mp3 or stills. |
| `encoderPreset` | `ultrafast` through `veryslow`, h264 only. Slower gives a smaller file at the same quality. |

## Transparent video

`timeline.background` fills any area the clips do not cover, with a hex colour (black by default) or `"transparent"`. png and webm keep transparency as an alpha channel, so you can render a lower third or a logo animation to lay over other video. mp4, gif and jpg have no transparency and refuse a transparent background instead of rendering it black.

```json
{
  "schemaVersion": 1,
  "output": { "format": "webm", "size": "1080p" },
  "timeline": {
    "background": "transparent",
    "tracks": [{ "clips": [{ "asset": { "type": "image", "src": "https://cdn.rendobar.com/assets/brand/logo-mark.png" }, "length": 3 }] }]
  }
}
```

## Part of a timeline, or one frame

`range` renders part of the timeline, from the second in `start` for `length` seconds. Leave out `length` to render to the end. On `jpg` and `png`, `start` is the moment captured, for a poster frame.

```json
"output": { "format": "png", "size": "1080p", "range": { "start": 4.5 } }
```

The [output reference](/docs/jobs/compose/reference/output) lists every output field.
