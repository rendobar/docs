A `shape` asset draws a rect, ellipse, circle, triangle, diamond or any SVG path. You need no image file, and the shape stays sharp at any output resolution.

```json
{
  "asset": { "type": "shape", "color": "#0A0A0ACC" },
  "transform": { "size": { "width": "100%", "height": "22%" }, "position": { "x": "50%", "y": "86%" } }
}
```

This is a see-through bar across the lower third to hold a title. Put it on a track below the text.

The clip's `transform` places a shape like any other clip. `size` is its box, `position` is its centre unless `anchor` says otherwise, and `rotate` turns it about that anchor. The asset only says what to draw.

With no `size`, a shape fills the frame, which gives you a tint or a background in one line. Like text, it has no duration of its own, so without `length` it runs to the end of its container.

`width` is a percent of the frame's width and `height` a percent of its height. Both also take pixels as plain numbers.

## Leave the height out to get a circle

Omit `size.height` and the box is square in pixels. This is the only way to get a true circle or square on a frame that is not square.

A `10%` by `10%` box on a 16:9 frame is 192 by 108 pixels, so rounding it fully gives a pill. Omit the height and the engine works out 17.8% for you.

```json
{
  "asset": { "type": "shape", "shape": "circle", "color": "#059669" },
  "transform": { "size": { "width": "12%" }, "position": { "x": "88%", "y": "18%" } }
}
```

`shape: "circle"` is an `ellipse` that always uses this rule, so it rejects a height if you set one. Leaving out the height works on every kind: a `rect` becomes a square and a `diamond` becomes a regular one.

## Anchor

`anchor: "topLeft"` points `position` at the box's corner instead of its centre. With it, you place letterbox bars without any maths.

```json
{
  "asset": { "type": "shape", "color": "#000000" },
  "transform": { "anchor": "topLeft", "position": { "x": "0%", "y": "90%" }, "size": { "width": "100%", "height": "10%" } }
}
```

## Fills, flat and gradient

`color` takes `#RRGGBB`, or the 8-digit `#RRGGBBAA` for constant transparency, as `#0A0A0ACC` does above.

Keep the clip's `opacity` for fades, since it fades the whole clip. Put constant transparency in the colour.

Give `color` two colours to make a gradient. `gradient` sets the direction: `vertical` (the default), `horizontal`, `diagonal` or `radial`.

```json
{
  "asset": { "type": "shape", "color": ["#E11D48", "#3B82F6"], "gradient": "diagonal" },
  "transform": { "size": { "width": "40%", "height": "30%" }, "position": { "x": "50%", "y": "50%" } }
}
```

The gradient spans the shape's own box, so a small badge shows the whole gradient. Stops take the 8-digit form too, so you can make a dark overlay that fades to nothing: `["#0A0A0A00", "#0A0A0AFF"]`.

## Outlines, with a real hole

`stroke` draws a border along the inside of the shape's edge, with `width` in output pixels. Add a `color` for a filled shape with a border. `radius` rounds both.

Leave out `color` and only the outline draws, with a transparent middle that shows the footage. This works on every kind except a path.

```json
{
  "asset": { "type": "shape", "shape": "ellipse", "stroke": { "color": "#F59E0B", "width": 5 } },
  "transform": { "size": { "width": "26%", "height": "40%" }, "position": { "x": "62%", "y": "40%" } }
}
```

## Drop shadows

`shadow` follows the shape, including its outline, rotation and animation. Every field has a default, so `"shadow": {}` gives a usable shadow.

```json
{
  "asset": {
    "type": "shape",
    "color": ["#FFFFFF", "#E5E7EB"],
    "radius": 0.3,
    "stroke": { "color": "#111827", "width": 3 },
    "shadow": { "color": "#00000099", "blur": 14, "x": 8, "y": 10 }
  },
  "transform": { "size": { "width": "34%", "height": "40%" }, "position": { "x": "30%", "y": "50%" } }
}
```

## Rotation turns about the anchor, not the frame

`transform.rotate` turns the shape clockwise in degrees about its own anchor, so it spins in place.

```json
{
  "asset": { "type": "shape", "color": "#FFFFFF" },
  "transform": { "rotate": 30, "size": { "width": "40%", "height": "0.8%" }, "position": { "x": "50%", "y": "72%" } }
}
```

There is no `line` or `square` type. A line is a rect with a small height, and `rotate` makes it diagonal, as above.

## Softness

`softness` runs from 0 to 1 and softens the edge. At 0.2 to 0.4, an ellipse looks like a spotlight or a vignette. A full-frame ellipse with `softness: 0.5` and a radial `["#00000000", "#000000CC"]` fill gives you a vignette with no image asset.

## Paths

`shape: "path"` takes SVG path data as a design tool exports it. `viewBox` sets the coordinate space it was drawn in and defaults to `"0 0 100 100"`. The engine scales the path to the transform's `size`, so the same data works at any size on any frame.

```json
{
  "asset": {
    "type": "shape",
    "shape": "path",
    "viewBox": "0 0 24 24",
    "path": "M12 21C12 21 3 14.5 3 8.5C3 5.5 5.5 3 8.5 3C10.4 3 12 4.5 12 4.5C12 4.5 13.6 3 15.5 3C18.5 3 21 5.5 21 8.5C21 14.5 12 21 12 21Z",
    "color": "#E11D48"
  },
  "transform": { "size": { "width": "20%" }, "position": { "x": "50%", "y": "50%" } }
}
```

`M L H V C S Q T Z` work in absolute and relative form. Elliptical arcs (`A`) are rejected, so re-export with arcs converted to curves. A path takes a fill, a gradient, a shadow, rotation and softness, but not a `stroke`.

## Animation

You animate a shape with [keyframes](/docs/jobs/compose/motion) on `position`, `size` and `rotate` in the transform, and on `color` and `radius` in the shape. For a progress bar, grow the width.

```json
{
  "asset": { "type": "shape", "color": "#FFFFFF" },
  "transform": {
    "anchor": "topLeft",
    "position": { "x": "2%", "y": "86%" },
    "size": [
      { "time": "0%", "value": { "width": "0%", "height": "1.5%" }, "easing": "smooth" },
      { "time": "100%", "value": { "width": "96%", "height": "1.5%" } }
    ]
  }
}
```

A shape that is square in pixels stays square as it grows, so an animated circle stays a circle. A solid colour can animate into a gradient, and keyframes on `radius` can round off a square. An animated `rotate` has no limit: 0 to 720 is two full turns.

## Combinations the API refuses

The engine has two ways to draw a shape, with different features. The API rejects the combinations below at submit time instead of rendering them wrong. Each error names the fix.

| Not combinable | Why | What to do instead |
| --- | --- | --- |
| `radius` on anything but a `rect` | only rectangles have corners | drop it |
| `radius` with no `color` | outline-only shapes are drawn the way that cannot round corners | give it a fill |
| `radius` with `rotate` or `softness` | the way that rounds corners cannot rotate or soften edges | drop one of them |
| `stroke` on a `path` | outlining arbitrary path data needs true path offsetting | draw the outline into the path itself |
| `speed` on a shape | there is no file to play faster | animate it with keyframes |

## What else a shape takes

[`blendMode`](/docs/jobs/compose/media#blend-modes) mixes a shape with the layer below. Effects apply to it as to any clip, and opacity keyframes fade it in and out. A track of only shapes renders as a base layer, so a solid colour background needs no files at all.

Shapes have no path stroke and no per-corner radius. For anything beyond that, use an `image` asset.

Every shape field is in the [shape reference](/docs/jobs/compose/reference/shape).
