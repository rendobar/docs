`3d.prepare` takes a mesh you already have and runs the print preparation on it: rebuilt as a closed solid, walls too thin to print closed, scaled, oriented, given a flat base, hollowed for resin, split to fit the plate and sliced. Without a printer it converts the mesh to another format.

It reads `glb`, `stl`, `obj`, `3mf` and `ply`. A `.gltf` with separate buffer files is not accepted, because one URL cannot carry them.

## Prepare a mesh for a printer

<CodeGroup>

```ts SDK
import { createClient } from "@rendobar/sdk";

const client = createClient({ apiKey: "rb_YOUR_KEY" });

const job = await client.jobs.run({
  type: "3d.prepare",
  inputs: { mesh: "https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Avocado/glTF-Binary/Avocado.glb" },
  params: { printer: "bambu-a1", sizeMm: 80, formats: ["stl", "3mf"] },
});

for (const file of job.output?.files ?? []) console.log(file.path, file.url);
```

```bash cURL
curl -X POST "https://api.rendobar.com/jobs" \
  -H "Authorization: Bearer rb_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "3d.prepare",
    "inputs": { "mesh": "https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Avocado/glTF-Binary/Avocado.glb" },
    "params": { "printer": "bambu-a1", "sizeMm": 80, "formats": ["stl", "3mf"] }
  }'
```

</CodeGroup>

<Warning>
Always set `sizeMm`. Without it the mesh is scaled to the default, 100 mm with a printer and 1000 mm without, not kept at its own size.
</Warning>

## Inputs

<ParamField body="mesh" type="string" required>
  URL of the mesh, or an uploaded asset's URL. `glb`, `stl`, `obj`, `3mf` or `ply`.
</ParamField>

<ParamField body="front" type="string">
  A photo of the object. Needed for `quality: "premium"`, which refines the surface against it, and to texture a mesh without a printer.
</ParamField>

## Parameters

`3d.prepare` takes the same parameters as [`3d.generate`](/jobs/3d-generate#parameters) except `prompt`, `enhancePrompt` and `candidates`: `printer`, `sizeMm`, `formats`, `quality`, `polycount`, `minWallMm` and every [print option](/jobs/3d-generate#print-options). The printer list, the output files and `output.data` are the same too.

Without a photo, `orient.mode` defaults to `auto`, which picks the pose needing the least support.

## Check a request for free

`POST /3d/validate` with `"type": "3d.prepare"` returns every setting the job would use, or each problem with a stable code. See the [code table](/jobs/3d-generate#check-a-request-for-free).
