Execute a custom FFmpeg command with whitelisted flags. The `inputs` map stages source files into the working directory by name. The command references them by bare name, and inline `-i` URLs also work.

<Info>
**Timeout:** 900 s max (plan-capped) · **Accepts:** video, audio, image
</Info>

## Request

<CodeGroup>

```bash cURL
curl -X POST https://api.rendobar.com/jobs \
  -H "Authorization: Bearer rb_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "ffmpeg",
    "inputs": {},
    "params": {
      "command": "ffmpeg -i https://cdn.rendobar.com/assets/examples/sample.mp4 -vf scale=1280:720 -c:v libx264 -crf 23 -preset fast output.mp4"
    }
  }'
```

```javascript JavaScript
const res = await fetch("https://api.rendobar.com/jobs", {

const { data } = await res.json();
```

```python Python
import requests
res = requests.post(

    },
)
```

## Parameters

<ParamField body="inputs" type="object" default="{}">
  Working directory for the command. Optional, defaults to an empty map. Each key is a path-safe filename staged under that exact name. Each value is the source for that file. Omit it when every input is an inline `-i` URL. A value is one of:

  <Expandable title="Input source shapes">
    <ResponseField name="URL string" type="string">
      Remote file. Shorthand for `{ "url": "..." }`.
    </ResponseField>
    <ResponseField name="url" type="object">
      `{ "url": "https://..." }`. Remote file, explicit form.
    </ResponseField>
    <ResponseField name="content" type="object">
      `{ "content": "...text..." }`. Inline text staged verbatim, up to 64 KB. For subtitles, `concat` lists, and LUTs with nothing to host.
    </ResponseField>
    <ResponseField name="ref" type="object">
      `{ "ref": "asset_abc123" }`. A file you already uploaded, by its asset ID (returned by the uploads endpoint).
    </ResponseField>
  </Expandable>

  Filters that read a file by name (`subtitles=`, `lut3d=`, `drawtext fontfile=`, `concat` lists) must get that file through `inputs`. They are not `-i` arguments. See the [FFmpeg guide](/guides/ffmpeg#input-sources).
</ParamField>

<ParamField body="command" type="string" required>
  Real FFmpeg command starting with `ffmpeg`. Input URLs go in `-i` positions, or reference staged `inputs` files by name.
</ParamField>

<ParamField body="outputFormat" type="enum" default="inferred">
  Container format. Inferred from the trailing filename if omitted. One of: `mp4`, `mkv`, `webm`, `mov`, `avi`, `ts`, `gif`, `png`, `jpg`, `mp3`, `wav`, `flac`, `ogg`, `aac`, `opus`, `m4a`, `srt`, `vtt`.
</ParamField>

<ParamField body="timeout" type="integer" default="120">
  Max execution time in seconds. Range 1–900. Plan caps apply (Free 5 min, Pro 15 min).
</ParamField>

## Response

```json
{ "data": { "id": "job_abc123", "status": "dispatched" } }
```

Poll `GET /jobs/{id}` until `status: "complete"`. On success the job carries an `output` object discriminated on `kind`. On failure it carries an `error` object. The filenames your command writes define the output.

<ResponseField name="output" type="object">
  Present when `status` is `complete`. The `kind` field tells you the shape.

  <Expandable title="output.kind: file">
    <ResponseField name="kind" type='"file"'>
      A single-file result. The command wrote one file.
    </ResponseField>
    <ResponseField name="url" type="string">
      Signed download URL for the file.
    </ResponseField>
    <ResponseField name="expiresAt" type="integer">
      Unix ms when `url` expires. Re-fetch the job to refresh.
    </ResponseField>
    <ResponseField name="poster" type="string | null">
      Signed URL for a generated poster frame, or `null`.
    </ResponseField>
    <ResponseField name="meta" type="object">
      Probed metadata: `format`, `width`, `height`, `durationMs`, `sizeBytes`. Each field is present when known.
    </ResponseField>
  </Expandable>

  <Expandable title="output.kind: stream">
    <ResponseField name="kind" type='"stream"'>
      An HLS or DASH result. The command wrote a manifest plus segments.
    </ResponseField>
    <ResponseField name="url" type="string">
      Playable manifest URL. Point a player at it directly.
    </ResponseField>
    <ResponseField name="manifest" type='"hls" | "dash"'>
      Which manifest format this stream uses.
    </ResponseField>
    <ResponseField name="baseUrl" type="string">
      Serving base URL for the prefix, trailing slash.
    </ResponseField>
    <ResponseField name="expiresAt" type="integer">
      Unix ms when every URL here expires. Re-fetch the job to refresh.
    </ResponseField>
    <ResponseField name="fileCount" type="integer">
      Total files under the served prefix.
    </ResponseField>
    <ResponseField name="files" type="array">
      Each file as `{ path, url, size }`.
    </ResponseField>
    <ResponseField name="manifestUrl" type="string">
      URL of the machine-readable `_manifest.json` listing every file.
    </ResponseField>
  </Expandable>

  <Expandable title="output.kind: set">
    <ResponseField name="kind" type='"set"'>
      An unordered collection: image sequences, `-f segment` output, a resolution ladder. No top-level playable URL.
    </ResponseField>
    <ResponseField name="baseUrl" type="string">
      Serving base URL for the prefix, trailing slash.
    </ResponseField>
    <ResponseField name="expiresAt" type="integer">
      Unix ms when every URL here expires. Re-fetch the job to refresh.
    </ResponseField>
    <ResponseField name="fileCount" type="integer">
      Total files under the served prefix.
    </ResponseField>
    <ResponseField name="files" type="array">
      Each file as `{ path, url, size }`.
    </ResponseField>
    <ResponseField name="manifestUrl" type="string">
      URL of the machine-readable `_manifest.json` listing every file.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="error" type="object">
  Present when `status` is `failed`.

  <Expandable title="error fields">
    <ResponseField name="code" type="string">
      Stable error code, e.g. `PROVIDER_ERROR`.
    </ResponseField>
    <ResponseField name="message" type="string">
      Human-readable summary of what went wrong.
    </ResponseField>
    <ResponseField name="detail" type="string | null">
      Extra context. For FFmpeg failures, the last ~2 KB of stderr. `null` when there is nothing to add.
    </ResponseField>
    <ResponseField name="retryable" type="boolean">
      Whether re-running the same job could succeed.
    </ResponseField>
  </Expandable>
</ResponseField>
