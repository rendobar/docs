Execute a custom FFmpeg command with whitelisted flags. The `inputs` map stages source files into the working directory by name. The command references them by bare name, and inline `-i` URLs also work.

<Info>
**Timeout:** 900 s max (plan-capped) · **Accepts:** video, audio, image
</Info>

## Request

<CodeGroup>

```bash cURL
curl -X POST https://api.rendobar.com/jobs \
  -H "Authorization: Bearer rb_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "ffmpeg",
    "inputs": {},
    "params": {
      "command": "ffmpeg -i https://cdn.rendobar.com/assets/examples/sample.mp4 -vf scale=1280:720 -c:v libx264 -crf 23 -preset fast output.mp4"
    }
  }'
```

```javascript JavaScript
const res = await fetch("https://api.rendobar.com/jobs", {
  method: "POST",
  headers: {
    "Authorization": "Bearer rb_YOUR_KEY",

  body: JSON.stringify({

});
const { data } = await res.json();
```

```python Python
import requests
res = requests.post(

        "params": {

        },
    },
)
```

## Parameters

<ParamField body="inputs" type="object" required>
  Working directory for the command. Each key is a path-safe filename staged under that exact name. Each value is the source for that file. `{}` when every input is an inline `-i` URL. A value is one of:

  <Expandable title="Input source shapes">
    <ResponseField name="URL string" type="string">
      Remote file. Shorthand for `{ "url": "..." }`.
    </ResponseField>
    <ResponseField name="url" type="object">
      `{ "url": "https://..." }`. Remote file, explicit form.
    </ResponseField>
    <ResponseField name="content" type="object">
      `{ "content": "...text..." }`. Inline text staged verbatim, up to 64 KB. For subtitles, `concat` lists, and LUTs with nothing to host.
    </ResponseField>
    <ResponseField name="ref" type="object">
      `{ "ref": "asset_abc123" }`. A file you already uploaded, by its asset ID (returned by the uploads endpoint).
    </ResponseField>
  </Expandable>

  Filters that read a file by name (`subtitles=`, `lut3d=`, `drawtext fontfile=`, `concat` lists) must get that file through `inputs`. They are not `-i` arguments. See the [FFmpeg guide](/guides/ffmpeg#input-sources).
</ParamField>

<ParamField body="command" type="string" required>
  Real FFmpeg command starting with `ffmpeg`. Input URLs go in `-i` positions, or reference staged `inputs` files by name.
</ParamField>

<ParamField body="outputFormat" type="enum" default="inferred">
  Container format. Inferred from the trailing filename if omitted. One of: `mp4`, `mkv`, `webm`, `mov`, `avi`, `ts`, `gif`, `png`, `jpg`, `mp3`, `wav`, `flac`, `ogg`, `aac`, `opus`, `m4a`, `srt`, `vtt`.
</ParamField>

<ParamField body="timeout" type="integer" default="120">
  Max execution time in seconds. Range 1–900. Plan caps apply (Free 5 min, Pro 15 min).
</ParamField>

## Response

```json
{ "data": { "id": "job_abc123", "status": "dispatched" } }
```

Poll `GET /jobs/{id}` until `status: "complete"`. The filenames your command writes define the output.

<ResponseField name="outputUrl" type="string">
  Signed download URL for a single-file output. Present when the command wrote one file.
</ResponseField>

<ResponseField name="output" type="object">
  Present when the command wrote multiple files (HLS/DASH, image sequences, `-f segment`).

  <Expandable title="output fields">
    <ResponseField name="type" type="enum">
      `stream` for an HLS/DASH playlist. `set` for an unordered collection.
    </ResponseField>
    <ResponseField name="url" type="string">
      Playable playlist for a `stream`. Absent for a `set`.
    </ResponseField>
    <ResponseField name="playlist" type="string">
      Entry playlist filename, e.g. `master.m3u8`.
    </ResponseField>
    <ResponseField name="baseUrl" type="string">
      Serving base URL for the prefix, trailing slash.
    </ResponseField>
    <ResponseField name="expiresAt" type="integer">
      Unix ms when every URL here expires. Re-fetch the job to refresh.
    </ResponseField>
    <ResponseField name="fileCount" type="integer">
      Total files under the served prefix.
    </ResponseField>
    <ResponseField name="files" type="array">
      Each file as `{ path, url, size }`.
    </ResponseField>
    <ResponseField name="manifestUrl" type="string">
      URL of the machine-readable `_manifest.json` listing every file.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errorDetail" type="string">
  On a failed job, the last ~2 KB of the real FFmpeg stderr for debugging.
</ResponseField>

See [output files](/guides/ffmpeg#output-files) in the guide for full request and response examples.
