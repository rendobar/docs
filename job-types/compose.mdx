`compose` renders a video from a JSON timeline. You describe an edit as tracks and clips, and Rendobar renders it to a single file. No FFmpeg filtergraphs, no local rendering.

## How it works

A timeline has two layers of structure:

- **Tracks** stack on top of each other. The first track is the background, each later track composites over the ones below it (overlays, captions, picture-in-picture).
- **Clips** sit on a track in time. Each clip has a `start` and `length` in seconds and wraps one asset (a video, image, text, or audio). Two clips on the same track are joined by a [transition](#transitions).

Every clip can carry effects: transform, color, speed, opacity, blur, blend mode, chroma key, and more. The sections below show each one, and every clip on this page is a real `compose` render.

## Your first render

The job's `params` is the timeline itself: `schemaVersion`, an `output`, and the `timeline` of tracks. This one plays two clips with a one-second crossfade between them.

<CodeGroup>

```ts SDK
import { createClient, outputUrl } from "@rendobar/sdk";

const client = createClient({ apiKey: "rb_YOUR_KEY" });

const job = await client.jobs.create({
  type: "compose",
  inputs: {},
  params: {
    schemaVersion: 1,
    output: { format: "mp4", resolution: { width: 1280, height: 720 }, fps: 30 },
    timeline: {
      tracks: [
        {
          clips: [
            { asset: { type: "video", src: "https://cdn.rendobar.com/assets/examples/a.mp4", trim: { from: 0, to: 3 } }, start: 0, length: 3 },
            { type: "transition", transition: "crossfade", duration: 1 },
            { asset: { type: "video", src: "https://cdn.rendobar.com/assets/examples/b.mp4", trim: { from: 0, to: 3 } }, start: 2, length: 3 },
          ],
        },
      ],
    },
  },
});

const result = await client.jobs.wait(job.id);
console.log(outputUrl(result));
```


## Output

Set the canvas with `output`. Pick the `resolution` and `fps`, and Rendobar fits every clip to it.

```json
"output": { "format": "mp4", "resolution": { "width": 1080, "height": 1920 }, "fps": 30, "videoCodec": "h264", "audioCodec": "aac" }
```

A `9:16` canvas with a `crop` on the clip turns landscape footage into a vertical Reel that fills the frame, no black bars.

## Transitions

To join two clips on a track, put a transition between them: `{ "type": "transition", "transition": "<name>", "duration": <seconds> }`. `wipe` and `slide` also accept `direction: "left" | "right" | "up" | "down"`.

| Transition | Effect |
| --- | --- |
| `crossfade` | A dissolves directly into B |
| `fade` | A dips through black, then B fades up |
| `wipe` | a hard edge sweeps across (directional) |
| `slide` | B slides in over A from an edge (directional) |
| `zoom` | B grows in from the center |

## Clip effects

Every effect below is a field on a clip. The source is on the left, the `compose` result on the right.

### Transform and Ken Burns

`transform` positions and scales a clip. Add `animateTo` and it animates from the start values to the end values over the clip, the Ken Burns move that brings a still photo to life.

```json
{ "asset": { "type": "image", "src": "photo.jpg" }, "start": 0, "length": 4,
  "transform": { "scale": 1.1, "position": { "x": "38%", "y": "48%" },
                 "animateTo": { "scale": 1.32, "position": { "x": "62%", "y": "52%" } } } }
```

### Picture-in-picture

Scale a clip down and position it on an overlay track to put a webcam over your content, for reactions and screen-shares.

```json
{ "asset": { "type": "video", "src": "webcam.mp4" }, "start": 0, "length": 3,
  "transform": { "scale": 0.3, "position": { "x": "80%", "y": "75%" } } }
```

### Speed

`speed` is a multiplier. Below `1` slows a clip down for a dramatic action beat, above `1` speeds a slow process into a timelapse.

```json
{ "asset": { "type": "video", "src": "waves.mp4", "trim": { "from": 1, "to": 2.2 } }, "start": 0, "length": 3, "speed": 0.4 }
```

### Color

`color` grades a clip. Set `contrast`, `saturation`, `temperature`, `brightness`, and `gamma` to set a cinematic mood, or push them to lift flat, hazy footage.

```json
{ "asset": { "type": "video", "src": "coast.mp4" }, "start": 0, "length": 3,
  "color": { "contrast": 1.12, "saturation": 1.2, "temperature": 6800, "gamma": 0.95 } }
```

### Filters

`filter` applies a one-shot look: `greyscale`, `negative`, `boost`, `muted`, `lighten`, `darken`, or `contrast`.

```json
{ "asset": { "type": "video", "src": "coast.mp4" }, "start": 0, "length": 3, "filter": "greyscale" }
```

### Chroma key

`chromaKey` removes a solid background color so you can drop a presenter onto any scene. Put the keyed clip on an overlay track above the new background.

```json
{ "asset": { "type": "video", "src": "greenscreen.mp4" }, "start": 0, "length": 3,
  "chromaKey": { "color": "#66DD09", "similarity": 0.28 } }
```

### Blend modes

`blendMode` controls how an overlay composites with the track below: `screen`, `multiply`, `overlay`, `add`, and more. A light-leak clip over your footage with `screen` adds a cinematic glow.

```json
{ "asset": { "type": "video", "src": "lightleak.mp4" }, "start": 0, "length": 3, "blendMode": "screen", "opacity": 0.7 }
```

### Opacity and blur

`opacity` takes a number or keyframes. Keyframe it from `0` to `1` and back for a clean fade in and out. `blur` softens a clip, useful as a backdrop that keeps overlaid text readable.

```json
"opacity": [ { "time": 0, "value": 0 }, { "time": 0.6, "value": 1 }, { "time": 2.4, "value": 1 }, { "time": 3, "value": 0 } ]
```

### Text and titles

A `text` asset renders a styled title. Set the `font`, `size`, `weight`, `color`, `position`, and an `animate` entrance (`fade`, `slideUp`, `slideDown`, `slideLeft`, `slideRight`). Put one text clip on its own track for a title card, another low and left for a lower-third name tag.

```json
{ "asset": { "type": "text", "text": "Coastal Escape",
    "style": { "font": "Inter", "weight": 800, "size": 84, "color": "#FFFFFF",
               "position": { "x": "50%", "y": "38%" }, "animate": { "type": "slideUp", "duration": 0.7 } } },
  "start": 0, "length": 4 }
```
