Poll `GET /jobs/{id}` until `status` is `complete`. The response then contains `output.file.url` (signed, 1-hour expiry) and `cost.formatted`.

<CodeGroup>

```ts SDK
import { createClient, outputUrl } from "@rendobar/sdk";

const client = createClient({ apiKey: "rb_your_key" });

// wait() polls until the job reaches a terminal status
const job = await client.jobs.wait("job_abc123");
console.log(job.status, outputUrl(job), job.cost?.formatted);
```

```bash cURL
curl https://api.rendobar.com/jobs/job_abc123 \
  -H "Authorization: Bearer rb_your_key"
```

```javascript JavaScript
const job = await fetch("https://api.rendobar.com/jobs/job_abc123", {
  headers: { "Authorization": "Bearer rb_your_key" },
}).then(r => r.json());
```

```python Python
job = requests.get(
    "https://api.rendobar.com/jobs/job_abc123",
    headers={"Authorization": "Bearer rb_your_key"},
).json()
```
